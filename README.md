## 项目介绍
本项目是一个基于TCP的客户端-服务器（C/S）通信系统，其中应用层通信协议支持多种网络服务功能。服务器端采用异步多线程模型，可并发处理多个客户端的请求；客户端提供交互式命令行菜单，用户可执行连接服务器、获取服务端时间与主机名、查询在线客户端列表、以及进行点对点消息转发等操作。

## 整体框架与设计思路
- 本项目的核心是一套头部包含长度字段的二进制协议，解决 TCP 流式传输的粘包问题。协议定义了请求、响应和服务器主动通知三种报文类型。
- 服务端采用主从多线程模型：主线程负责接受新连接，为每个客户端创建独立工作线程。工作线程解析请求后，根据功能码执行相应操作，并返回响应。同时全局客户端列表通过互斥锁保护以实现线程安全。
- 客户端采用生产者-消费者模型与多线程协作：主线程处理用户输入并发送请求；独立接收线程负责从 Socket 流中解析完整协议包并放入共享消息队列。
- 核心功能如消息转发通过服务器中转实现：当客户端A向客户端B发送消息时，服务器验证B在线后，会主动向B发送一个“指示”类型的协议包，从而实现点对点通信的模拟。

## 环境要求
- Linux（Ubuntu 或 WSL 等）
- g++

## 编译方法（推荐使用 VS Code）
在项目根目录执行：
```bash
mkdir -p build
g++ -std=c++11 -O2 -pthread -o server/server server/server.cpp common/protocol.cpp
g++ -std=c++11 -O2 -pthread -o client/client client/client.cpp common/protocol.cpp
```

## 启动通信系统

### 启动服务器

打开终端（仅支持单服务器），在项目根目录运行：

```bash
./server/server
```

### 启动客户端

打开另一终端（支持多客户端），在项目根目录运行：

```bash
./client/client
```

根据提示在终端中可完成各类通讯操作：
- 连接服务器
- 获取 time/hostname
- 获取客户端列表
- 接送消息
- 断开连接/退出
